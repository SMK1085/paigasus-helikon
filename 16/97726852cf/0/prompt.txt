  **M1. The repair can swap two results in a new-layout `ParallelAgent` log with a repeated id.**
  - Location: `session.rs` step 2, about lines 452-470.
  - Two branches both use Gemini `fc_0`. The merged stream can poll branch B between A's `HandoffItem` and A's transfer result. The log is then `TC fc_0(T) HO TC fc_0(S) TR fc_0(transferred) TR fc_0(S data)`.
  - Step 2 gives "transferred" to S (the most recent open non-transfer call) and S's data to T. The repair then projects `TC T, TR data, TC S, TR transferred`. Without the repair, FIFO would pair the results correctly.
  - This breaks the spec property "a new-layout log projects exactly as today". The spec does exclude `ParallelAgent` from the G3/G4 scope, so this is a scope edge.
  - Optional hardening: a `ToolReturned` that is directly after the HO run (at `HO+1+k`) closes the transfer call first.
  
  **M2. AG-UI: a delta-only call followed by an item-only reuse of its id shares one occurrence.**
  - Location: `map.rs` `occurrence_for_item`.

  - This needs a streaming parent and a non-streaming child with colliding ids, so it is rare. Neither T14 nor be49dde3 covers it.
